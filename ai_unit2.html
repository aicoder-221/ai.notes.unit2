🎯 Data Science Pipeline 10 Steps
📌 Definition The John Rollins Data Science Pipeline is a systematic, 10-step process used to solve real-world problems using data and AI — from understanding the business problem to deploying and improving models.
Systematic Process AI & ML Real-world Problems John Rollins

👇 Click any step to expand details

01
Business Understanding
🎯

Define the problem clearly in business terms.

  • Set goals & success criteria
  • Understand business impact
  • Example: Reduce stockouts by predicting demand
02
Analytic Approach
🧭

Choose the type of analysis or model needed.

  • Prediction → Regression
  • Classification → Category output
  • Grouping → Clustering
03
Data Requirements
📋

Decide what data is needed.

  • Target variable (output to predict)
  • Features (input variables)
  • Data format: CSV, Database
  • Time period (e.g., last 2 years)
04
Data Collection
🗄️

Collect data from various sources.

  • Databases & APIs
  • Surveys
  • Public datasets
05
Data Understanding
🔍

Explore and analyse data to check quality.

  • Identify patterns
  • Find missing values
  • Detect outliers
  • Validate data relevance
06
Data Preparation
🧹

Convert raw data into usable format — most important step!

  • Cleaning (remove errors)
  • Transformation (scaling, encoding)
  • Feature engineering (create new features)
07
Modelling
🤖

Train machine learning model using prepared data.

  • Select algorithm
  • Train on dataset
  • Tune parameters (hyperparameters)
08
Evaluation
📏

Check model performance using metrics.

  • Accuracy is acceptable
  • Model meets business goal
  • MAE, MSE, RMSE (regression)
  • Accuracy, F1, Precision, Recall (classification)
09
Deployment
🚀

Implement model in real-world system.

  • Website / App integration
  • Inventory system
  • Generates predictions automatically
10
Feedback
🔄

Continuously improve model based on real results.

  • Collect real-world results
  • Retrain model regularly
  • Fix errors
  • Monitor performance
⚡ Quick Revision — Pipeline Order
  • Business Understanding → Analytic Approach → Data Requirements → Collection
  • → Understanding → Preparation → Modelling → Evaluation → Deployment → Feedback
  • Data Preparation is the most time-consuming & important step

Splitting data prevents overfitting and evaluates generalization.

80% — Training

📏 Evaluation & Metrics Step 8
Metric 01
MAE — Mean Absolute Error
MAE = Σ|yᵢ - ŷᵢ| / n
Average of absolute errors Easy to understand Same unit as output
Metric 02
MSE — Mean Squared Error
MSE = Σ(yᵢ - ŷᵢ)² / n
Squares errors → penalizes large mistakes Sensitive to outliers
Metric 03
RMSE — Root Mean Squared Error
RMSE = √[ Σ(yᵢ - ŷᵢ)² / n ]
Square root of MSE Same unit as actual values Most commonly used metric
📌 Confusion Matrix Terms ✅ TP = True Positive (correctly predicted positive) ✅ TN = True Negative (correctly predicted negative) ❌ FP = False Positive (predicted positive, actually negative) ❌ FN = False Negative (predicted negative, actually positive)
Metric 01
Accuracy
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Overall correctness of the model
Metric 02
Precision
Precision = TP / (TP + FP)
Out of predicted positives, how many are actually correct
Metric 03
Recall (Sensitivity)
Recall = TP / (TP + FN)
Out of actual positives, how many were detected
Metric 04
F1 Score
F1 = 2 × (Precision × Recall) / (Precision + Recall)
Harmonic mean — balance between Precision & RecallUse when classes are imbalanced
⚡ Memory Trick — Regression
MAE = |absolute| error MSE = squared² error RMSE = √MSE
  • MAE → simplest, ignore outlier weight
  • MSE → outliers punished more (squared)
  • RMSE → same units as output → most interpretable
⚡ Memory Trick — Classification
  • Accuracy → how often is it right overall
  • Precision → when it says yes, is it correct?
  • Recall → does it catch all the actual positives?
  • F1 → use when precision & recall both matter
⚠️ Exam Warning Never use only Accuracy on imbalanced datasets — use F1 Score instead!
📝 Section Summary

Regression uses MAE/MSE/RMSE (numerical output). Classification uses Accuracy, Precision, Recall, and F1 (categorical output). Always choose the metric that aligns with business goals. For imbalanced data, F1 is preferred over Accuracy.

⚖️ Overfitting vs Underfitting Core Concept
🎯❌
Overfitting
Model memorizes training data. Performs poorly on new, unseen data. Too complex.
High Variance
✅
Ideal Model
Balanced complexity. Generalizes well. Good accuracy on both train and test data.
Good Generalization
📉❌
Underfitting
Model too simple. Misses patterns. Poor accuracy even on training data.
High Bias
🔁 Validation Methods Step 7–8
✂️ Train-Test Split
✔ Fast✘ Less Reliable
  • Simple one-time split
  • 80% train / 20% test
  • Quick to implement
  • Results can vary based on split
🔁 K-Fold Cross Validation
✔ Accurate✔ Full Dataset✘ Slower
  • Dataset divided into K folds
  • Model trained K times
  • Each fold used as test once
  • More reliable performance estimate

Q8 · Short Answer
Name the 4 types of Data Analytics in order (Descriptive → Prescriptive).
✅ Descriptive → Diagnostic → Predictive → Prescriptive. Each builds on the previous: What happened → Why → What will happen → What to do.
Q9 · Case Based
A hospital wants to detect cancer patients. Which metric is more critical — Precision or Recall? Why?
✅ Recall is more critical. Missing an actual cancer case (False Negative) is far more dangerous than a false alarm. High Recall ensures all actual cancer patients are detected, even at the cost of some false positives.
Q10 · Case Based
You are predicting house prices. Which evaluation metrics would you use? Why not Accuracy?
✅ Use MAE, MSE, or RMSE — these are regression metrics for numerical outputs. Accuracy is only for classification (categorical output). Since house price is a number, we need metrics that measure how far off our predictions are from actual values.

🏁 Final Summary

The Data Science Pipeline has 10 steps organized in 5 modules. Data Preparation (Step 6) is most critical. Evaluation uses regression metrics (MAE/MSE/RMSE) or classification metrics (Accuracy/Precision/Recall/F1) depending on output type. Always use F1 for imbalanced data. K-Fold is more reliable than simple train-test split. Good luck! 🎯
